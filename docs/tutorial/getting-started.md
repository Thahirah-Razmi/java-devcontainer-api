# Getting Started

This tutorial walks through setting up the Java Dev Container API and running the Spring Boot application inside the development container.

## Prerequisites

Before starting, install:

- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)

Java does not need to be installed on the host machine because the Java 21 runtime is provided by the development container.

## 1. Clone the Repository

Clone the repository and enter the project directory:

```bash
git clone <your-repository-url>
cd java-devcontainer-api
