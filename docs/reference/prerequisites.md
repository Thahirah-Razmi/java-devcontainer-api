# Prerequisites

The project is designed to run inside a VS Code Dev Container.

## Required software

Install the following on the host machine:

- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)

## Host Java installation

Java does **not** need to be installed on the host machine.

The development container provides the Java 21 runtime and the Maven build environment.

## Container-provided tools

The development container provides:

- Java 21
- Maven
- Git
- Python 3
- MkDocs
